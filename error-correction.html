Correction d'erreurs quantiques

Code de répétition à trois qubits : détection et correction d'une erreur de bit X. Cette démonstration simule un état logique de la forme α|000⟩ + β|111⟩.

Le code corrige une seule erreur X. Les erreurs de phase Z et les erreurs multiples ne sont pas corrigées par ce code.

Diagnostic et correction

Amplitudes non nulles

Simulation classique idéale, sans processeur quantique réel. Les mesures de parité sont simulées comme des mesures non destructives des stabilisateurs Z₀Z₁ et Z₁Z₂. Le code à trois qubits protège contre une erreur X unique, pas contre une erreur quantique arbitraire.
